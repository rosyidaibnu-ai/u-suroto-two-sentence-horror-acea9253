# Two-Sentence Horror

An original two-sentence horror story, written for make.fun's
[Two-Sentence Horror](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253)
bounty. A laundrette owner notices a small weekly ritual — one child's sock,
always the left one — and one morning the ritual changes.

`main.py` validates the story (exactly two sentences, 1–400 characters) and
writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
